# PowerGrid (Энергосеть) — мод для Minecraft 1.21.1 (Fabric)

Энергосистема внутри игры: генерация → кабели → нагрузка, с аккумуляторами, перегрузкой и блэкаутами.

## Блоки и предметы

| Блок | Что делает |
|---|---|
| Угольный генератор | ПКМ углём / древесным углём (80 с) или угольным блоком (800 с). Пока горит — **20 EU/t** |
| Солнечная панель | **8 EU/t** днём под открытым небом, 2 EU/t в дождь, 0 ночью |
| Аккумулятор | 100 000 EU, заряд/разряд до **64 EU/t** |
| Медный кабель | пропускает до **64 EU/t** |
| Силовой кабель | пропускает до **512 EU/t** |
| Электролампа | потребляет **4 EU/t**, светится, когда есть питание |
| Мультиметр | ПКМ по любому блоку сети — генерация, нагрузка, баланс, заряд, слабейший кабель |

## Как работает сеть (раз в секунду)

1. Генерация ≥ нагрузки — все лампы горят, излишек заряжает аккумуляторы.
2. Генерация < нагрузки — дефицит покрывают аккумуляторы.
3. Не хватает и их — **срабатывает автомат** (щелчок): вся сеть гаснет, генераторы заряжают аккумуляторы.
4. Поток в сети больше пропускной способности самого слабого кабеля — **кабель сгорает** (дым, искры).
   Пример: 17+ ламп (68 EU/t) на медном кабеле сожгут его — нужен силовой.

## Рецепты (верстак)

- **Медный кабель ×8:** 3 сушёные ламинарии / 3 медных слитка / 3 сушёные ламинарии
- **Силовой кабель ×4:** 3 ламинарии / медный кабель, медный блок, медный кабель / 3 ламинарии
- **Угольный генератор:** 3 железа / железо, печь, железо / медь, редстоун, медь
- **Солнечная панель:** 3 стекла / лазурит, редстоун, лазурит / 3 медных слитка
- **Аккумулятор:** медь, редстоун, медь / редстоун, блок редстоуна, редстоун / медь, редстоун, медь
- **Электролампа ×2:** _, стекло, _ / стекло, светокаменная пыль, стекло / _, медь, _
- **Мультиметр:** _, стеклянная панель, _ / медь, редстоун, медь / _, медь, _

## Сборка

Нужен **JDK 21**. В папке проекта:

```
gradlew build        (Windows)
./gradlew build      (Linux/macOS)
```

Готовый мод: `build/libs/powergrid-1.0.0.jar` → в папку `.minecraft/mods` вместе с Fabric API для 1.21.1.

Запуск игры прямо из проекта для теста: `gradlew runClient`.
